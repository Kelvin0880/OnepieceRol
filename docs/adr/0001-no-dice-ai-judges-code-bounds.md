# No dice: the AI judges, code only bounds and applies

Combat, flight, fate at zero life, stealth, recruiting and world events used to be rolled. The owner ordered dice out: the AI referee and judge decide from level, health, stamina, kit and what the player wrote. Code never picks an outcome; it only clamps and applies a verdict (maximum life lost per exchange, a win needs the rival low, a fighter who was just attacked cannot be hurt in the same verdict) and, when no valid verdict arrives, changes nothing. A test fails if a dice primitive returns. Deterministic stand-ins exist only for scripted checks (`REFEREE_STUB`, `JUDGE_STUB`). Consequence: rules the AI is told in a prompt (such as Logia immunity) can be broken by it, so where a rule is certain, a conservative code backstop is added around the verdict instead of a new roll.
